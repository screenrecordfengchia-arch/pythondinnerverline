## 程式用途

主辦人收到「桌遊體驗」和「電影欣賞」兩段報名文字，裡面有多餘空白、大小寫不一致，還有人重複報名。這個程式會：

1. 移除半形空白、轉小寫、用逗號拆成 `list`（保留重複，方便看原始報名狀況）
2. 轉成 `set` 去重，用交集、聯集、兩個方向的差集比較兩場名單
3. 排序名單，用切片 `[:2]` 取得通知名單前兩位
4. 用 `dict`（`summary`）保存人數、人次與各場應收，再用 f-string 輸出摘要

| 型別 | 在本題保存什麼 |
| --- | --- |
| `tuple` | 固定的兩個活動名稱 `activity_names` |
| `list` | 整理後保留重複的名單、排序後的名單 |
| `set` | 去重後的名單，用來做集合運算 |
| `dict` | `unit_fees` 查每人費用；`summary` 保存人數與金額 |

## 問題回答

**問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？**

桌遊串列是 `['amy', 'ben', 'amy', 'cora']`，看起來 4 筆，但 amy 其實報名了兩次，人還是同一個。規則說同一個人只收一次錢，所以真正要收費的是 amy、ben、cora 這 3 個人，3 × 120 = 360 元。如果直接用 list 的長度 4 來算，就會多收 amy 120 元。

我覺得 list 就像「報名紀錄」：它保留了每一筆報名的**順序**和**重複**，看得出誰報了兩次，但沒辦法直接知道有幾個不同的人。set 比較像「參加者名冊」：它把重複的人合併成一個，所以 `len()` 就是真正的人數，也能做交集、差集；但它失去了**順序**和**重複次數**，看不出 amy 報了兩次，也不能用索引取第幾個，要先 `sorted()` 才能顯示和切片。

**問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。**

測試三去重後，兩場都是 `{amy, ben, cora}`，兩個集合完全一樣：

- 交集 = 聯集 = `{amy, ben, cora}`，兩個差集都是空的 `[]`
- 所以「總不重複人數」= 聯集的人數 = **3 人**

但「報名人次」是兩場各自算人數再加起來：3 + 3 = **6 人次**。因為這 3 個人每個人都參加了兩場，所以每人算 2 人次。

收費也是每場分開算，跟有沒有同一個人無關：桌遊 3 × 120 = 360 元，電影 3 × 80 = 240 元，總共 360 + 240 = **600 元**，跟測試一一樣。如果錯用「總不重複人數 3 人」來收，就會少收很多錢。
