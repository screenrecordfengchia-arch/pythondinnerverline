## 問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**

我的理解是，加了引號的 `"4"` 在 Python 眼中只是一個「字」，就像寫在紙上的符號，它不知道這代表 4 個人。我試過直接寫 `1220 / "4"`，結果跳出 `TypeError`。用 `int(people)` 把它變成真正的數字 `4` 之後，程式才會乖乖算出每人 305 元。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**

會變成 1210 元，算法是：

- 先扣折價券：1200 − 100 = 1100
- 再算服務費：1100 × 0.10 = 110
- 總額：1100 + 110 = 1210

題目規定的是 1220 元，差了 10 元。原因是服務費的「基礎」不一樣：題目是用原本的 1200 元算 10%，所以服務費是 120；如果先扣折價券，那 100 元就不用付服務費，服務費少了 100 × 10% = 10 元。所以計算順序不同，結果就會不同，要照餐廳的規定來算。
