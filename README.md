## 問題回答

**問題一：為什麼 `"4"` 要先轉成數字，才能用於本題的分攤計算？**

`"4"` 是字串（`str`），對 Python 來說只是文字，不是數量。如果直接用 `1220 / "4"` 會出現 `TypeError`，因為數字不能除以文字。用 `int("4")` 轉成整數 `4` 之後，才能算出 `1220 / 4 = 305`。

**問題二：如果先扣折價券，再依剩餘餐費計算服務費，第一組的應付總額會變成多少？為什麼和題目規定的結果不同？**

會變成 **1210 元**：(1200 − 100) = 1100，服務費 1100 × 0.10 = 110，總額 1100 + 110 = 1210。
題目規定服務費要用「原始餐費」1200 計算，服務費是 120，所以總額是 1200 + 120 − 100 = 1220。兩者差 10 元，因為先扣折價券會讓服務費的計算基礎變小（100 × 10% = 10 元）。
